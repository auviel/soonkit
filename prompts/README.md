# Prompts

Paste these into Cursor, Claude, ChatGPT, Copilot, or any other agent. The agent should already be in this repo (or you should attach `llms.txt` + `public/soon.config.json`).

| Prompt | Use when |
|--------|----------|
| [starter.md](starter.md) | First message: brand it and ship it |
| [brand.md](brand.md) | Only restyle / rewrite copy |
| [deploy.md](deploy.md) | Only deploy |
| [go-live.md](go-live.md) | Hide the editor and publish |

In Cursor you can also say the same thing in plain language — `AGENTS.md` and the project skills pick it up.
